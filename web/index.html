How it works

  1. Train from scratch. A ~99K-parameter CNN (3 conv blocks + 2 FC layers), built quantization-friendly with fuseable conv-BN-ReLU triples.
  2. Static INT8 post-training quantization. Fuse modules, insert observers, calibrate on real data, then convert weights and activations to 8-bit integers.
  3. Benchmark honestly. Compare FP32 vs INT8 on accuracy, on-disk size, and per-image latency on the ARM-oriented qnnpack backend.
  4. Run on the edge. The FP32 graph is exported to ONNX and runs client-side here via WebAssembly, the same portability story that makes on-device inference practical.

Note: this page runs the FP32 ONNX graph for predictions (broad browser support). The size and latency wins above are the measured INT8 results from the repo.
