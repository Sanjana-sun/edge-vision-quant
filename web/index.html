Model card

  1. Architecture. TinyConvNet, ~99K params: 3 conv blocks (conv-BN-ReLU-maxpool) + 2 FC layers, built with fuseable blocks and Quant/DeQuant stubs.
  2. Quantization. Static INT8 post-training: fuse modules, insert observers, calibrate on real data, convert weights and activations to 8-bit on the qnnpack backend.
  3. Serving. FastAPI loads both models; the FP32 graph also exports to ONNX for portability.
  1. Dataset. FashionMNIST, 28×28 grayscale, 10 classes, normalized with mean 0.286 / std 0.353.
  2. Results. INT8 is 3.78× smaller and ~1.8× faster than FP32 for a 0.13-point accuracy change.
  3. Limitations. Trained only on FashionMNIST, so uploads and drawings work best as a single light clothing item on a dark background; the weakest class is Shirt (confused with T-shirt/Coat).
